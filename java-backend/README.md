# Lingmou Java Backend

This module moves the platform backend to Spring Boot while keeping model inference in Python.

## Boundary

Java owns:

- upload validation and storage;
- image, video, and audio detection orchestration;
- task IDs and batch semantics;
- SQLite history, summaries, and analytics;
- result JSON persistence and `/outputs/**` resources;
- compatible chat completion endpoints;
- API error handling and configuration.

Python owns:

- face detection and media preprocessing;
- DFD-FCG visual inference;
- audio model inference;
- heatmaps, keyframes, curves, and preview generation.

The Python adapter is `algorithm_service/main.py`. It exposes inference only and does not contain
history, page rendering, chat, or other business logic.

## Requirements

- Java 21 or newer
- Maven 3.6 or newer
- Node.js 20 or newer for building the Vue frontend
- The existing Python model environment when real inference is required

## Run

Use one shared absolute output path so Java can serve artifacts generated by Python:

```bash
export OUTPUT_ROOT=/absolute/path/to/deepfake/outputs-java
export MODEL_CFG_PATH=/absolute/path/to/setting.yaml
export MODEL_CKPT_PATH=/absolute/path/to/model.ckpt

# Terminal 1: existing Python environment
bash ./run_algorithm_service.sh

# Terminal 2
cd web-frontend
npm install
npm run build

cd ../java-backend
mvn spring-boot:run
```

Java listens on `8080` and the internal Python service listens on `8100` by default.

## Configuration

| Environment variable | Default | Purpose |
| --- | --- | --- |
| `APP_HOST` | `0.0.0.0` | Java bind address |
| `APP_PORT` | `8080` | Java HTTP port |
| `OUTPUT_ROOT` | `outputs-java` | Shared uploads and artifacts |
| `SQLITE_PATH` | `outputs-java/app.db` | Java-owned history database |
| `ALGORITHM_BASE_URL` | `http://127.0.0.1:8100` | Python inference service |
| `MAX_IMAGE_MB` | `20` | Image upload limit |
| `MAX_VIDEO_MB` | `500` | Video upload limit |
| `MAX_AUDIO_MB` | `100` | Audio upload limit |
| `MAX_BATCH_FILES` | `20` | Maximum files in one detection batch |
| `AI_CHAT_API_KEY` | empty | Chat service credential |

No API credential has a source-code default.

## Public APIs

- `GET /api/health`
- `POST /api/detect/image`
- `POST /api/detect/video`
- `POST /api/detect/audio`
- `GET /api/history`
- `GET /api/history/summary`
- `GET /api/history/{taskId}`
- `GET /api/history/{taskId}/analytics`
- `POST /api/chat/ask`
- `POST /api/chat/stream`

Detection endpoints accept the existing `file`, `files`, and `batch_name` multipart fields.

## Frontend

The Vue 3 application is under `web-frontend`. It covers the detection workspace, image/video/audio
uploads, result evidence, history and analytics, chat, and the recognition guide. Maven copies its
production build into Spring Boot, while Vite proxies API calls during frontend development.

See [algorithm-contract.md](docs/algorithm-contract.md) for the internal Java/Python contract.
