# JSON文件格式 - 简单易懂版

## 🎯 一句话总结
JSON文件告诉程序：**哪些视频要用来训练/测试，以及这些视频之间的配对关系**

## 📝 最简单的理解

想象一下，JSON文件就像一张**清单**，列出了所有要用的视频。

### 格式就是这样的：

```json
[
  ["视频1"],
  ["视频2"],
  ["视频3", "视频4"]
]
```

**规则很简单：**
- 每个 `["..."]` 代表一个条目
- 如果里面只有1个视频ID → 这是**真实视频**
- 如果里面有2个视频ID → 这是**假视频对**（两个视频合成一个假视频）

## 🔍 具体例子

### 例子1：最简单的JSON

```json
[
  ["000"],
  ["001"],
  ["002", "003"]
]
```

**这表示什么？**
- `["000"]` → 真实视频，文件名是 `000.avi`
- `["001"]` → 真实视频，文件名是 `001.avi`  
- `["002", "003"]` → 假视频对，文件名是 `002_003.avi`（用002和003合成的假视频）

### 例子2：更完整的例子

```json
[
  ["000"],
  ["001"],
  ["002"],
  ["003", "004"],
  ["005", "006"]
]
```

**解释：**
- 前3个是真实视频：`000.avi`, `001.avi`, `002.avi`
- 后2个是假视频对：
  - `003_004.avi`（用视频003和004合成的假视频）
  - `005_006.avi`（用视频005和006合成的假视频）

## 📁 文件放在哪里？

```
你的数据集文件夹/
└── csv_files/
    ├── train.json    ← 训练集用的视频列表
    ├── val.json      ← 验证集用的视频列表
    └── test.json     ← 测试集用的视频列表
```

## 🎬 视频文件在哪里？

假设你的数据集在 `datasets/ffpp/`：

```
datasets/ffpp/
├── real/              ← 真实视频文件夹
│   └── c23/
│       └── videos/
│           ├── 000.avi
│           ├── 001.avi
│           └── 002.avi
│
├── DF/                 ← 假视频文件夹（DeepFakes类型）
│   └── c23/
│       └── videos/
│           ├── 003_004.avi
│           └── 005_006.avi
│
└── csv_files/
    └── train.json      ← JSON文件在这里
```

## 💡 为什么要配对？

假视频通常是由**两个真实视频**合成的：
- **背景视频**（back）：提供身体、背景
- **前景视频**（fore）：提供脸部

所以 `["003", "004"]` 意思是：
- 用视频003做背景
- 用视频004的脸
- 合成后的假视频叫 `003_004.avi`

## ✍️ 如何创建JSON文件？

### 方法1：手动写（最简单）

1. 打开文本编辑器
2. 创建一个文件叫 `train.json`
3. 写入内容：

```json
[
  ["000"],
  ["001"],
  ["002", "003"]
]
```

4. 保存到 `datasets/ffpp/csv_files/train.json`

### 方法2：用Python生成

```python
import json

# 列出你要用的视频
videos = [
    ["000"],        # 真实视频
    ["001"],        # 真实视频
    ["002", "003"], # 假视频对
]

# 保存为JSON
with open("datasets/ffpp/csv_files/train.json", "w") as f:
    json.dump(videos, f, indent=2)  # indent=2 让格式更美观
```

## ⚠️ 常见错误

### ❌ 错误1：视频ID带扩展名
```json
[
  ["000.avi"]  ← 错误！不要带.avi
]
```

### ✅ 正确
```json
[
  ["000"]  ← 正确！只要ID
]
```

### ❌ 错误2：不是数组的数组
```json
[
  "000",  ← 错误！应该是 ["000"]
  "001"
]
```

### ✅ 正确
```json
[
  ["000"],  ← 正确！
  ["001"]
]
```

### ❌ 错误3：视频文件不存在
JSON里写了 `["003", "004"]`，但文件夹里没有 `003_004.avi` 文件

## 🔧 检查你的JSON文件

用这个简单的Python代码检查：

```python
import json

# 读取JSON文件
with open("datasets/ffpp/csv_files/train.json") as f:
    data = json.load(f)

# 打印出来看看
print("JSON内容：")
for i, item in enumerate(data):
    if len(item) == 1:
        print(f"  {i+1}. 真实视频: {item[0]}")
    else:
        print(f"  {i+1}. 假视频对: {item[0]}_{item[1]}")

print(f"\n总共 {len(data)} 个视频/视频对")
```

2. **格式 = 数组的数组**
3. **1个ID = 真实视频**
4. **2个ID = 假视频对**
5. **文件位置 = csv_files文件夹**
