# trace_gen 导图

- 模块目标
- 生成可复现的请求轨迹与负载分布
- 让性能测试更接近真实业务流量

- 输入
- 基础数据集或原始日志
- 目标 QPS/并发曲线
- 请求长度分布（输入/输出 token）
- 场景标签（高峰/低峰/突发）

- 主流程
- 读取源数据
- 清洗与抽样
- 生成请求事件序列
- 生成时间戳与并发模式
- 导出 trace 文件
- 校验统计特征

- 输出
- trace 文件（json/csv/parquet）
- 分布统计报告
- 可视化图（长度分布/速率曲线）

- 关键校验
- 样本总量与窗口时长
- 输入长度分布拟合度
- 突发峰值与平均负载偏差
- 可重复随机种子

- 与评测系统对接
- 对接 llm_perf benchmark 作为请求输入
- 对接 general_perf 批量任务调度
- 输出统一 schema 便于自动化回放

- 风险点
- 统计分布失真
- 时间序列抖动过大
- 数据脱敏与合规问题
