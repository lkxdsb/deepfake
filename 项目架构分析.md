# DFD-FCG-GRU-CCSA 项目整体架构分析

## 📋 项目概述

这是一个基于CLIP视觉-语言基础模型的视频Deepfake检测项目，项目通过**面部组件引导（FCG）**和**跨组件自注意力（CCSA）**机制，结合**GRU时序建模**，实现了高泛化性的伪造视频检测。

---

## 🏗️ 整体架构

### 核心技术栈
- **基础模型**: CLIP (ViT-L/14)
- **时序建模**: Bidirectional GRU + Multi-scale Temporal Pooling
- **空间建模**: Facial Component Guidance (FCG) + Cross-Component Self-Attention (CCSA)
- **训练框架**: PyTorch Lightning 2.2.0

class EVLDecoder(nn.Module):
    def __init__(self, num_frames=8, enable_ccsa=True, ...):
        # 时序卷积：捕获局部时序模式
        self.temporal_conv = nn.ModuleList([

        # 时序位置编码

            TemporalCrossAttention(spatial_size, in_feature_dim)

                CrossComponentSelfAttention(...)
            ])

**关键机制**：
- **Temporal Cross Attention**: 计算相邻帧之间的空间对应关系
- **CCSA**: CLS token与patch tokens之间的双向注意力交互

#### 核心代码 - GRU时序建模：
```python
class SynoDecoder(nn.Module):
    def __init__(self, ...):
        # GRU捕获帧间时序依赖
        self.temporal_gru = nn.GRU(
            input_size=d_model,
            hidden_size=self.temporal_hidden,
            num_layers=1,
            batch_first=True,
            bidirectional=True  # 双向GRU
        )
        
        # 多尺度时序池化分支
        self.temporal_pool_branches = nn.ModuleList([
            nn.Sequential(
                nn.Conv1d(d_model, branch_width, kernel_size=3, stride=1),
                nn.GELU(),
                nn.AdaptiveAvgPool1d(1)
            ),
            nn.Sequential(
                nn.Conv1d(d_model, branch_width, kernel_size=3, stride=2),
                nn.GELU(),
                nn.AdaptiveAvgPool1d(1)
            )
        ])
        
    def _temporal_contextualize(self, frame_tokens, y_t):
        # GRU处理帧序列
        _, h_n = self.temporal_gru(frame_tokens)  # (b, t, width)
        gru_feat = h_n.transpose(0, 1).reshape(b, -1)
        
        # 多尺度特征提取
        multi_scale_feats = []
        temporal_tokens = frame_tokens.transpose(1, 2)
        for branch in self.temporal_pool_branches:
            multi_scale_feats.append(branch(temporal_tokens).flatten(1))
        
        # 特征融合
        fused = torch.cat([y_t, gru_feat, *multi_scale_feats], dim=-1)
        return self.temporal_fusion(fused)
```

### 3️⃣ **CCSA (Cross-Component Self-Attention)**
**文件**: `src/model/clip/svl.py` 和 `evl.py`

#### 核心思想：
CLS token（全局表示）与 Patch tokens（局部表示）之间的双向信息交互

```python
class CrossComponentSelfAttention(nn.Module):
    def forward(self, x: torch.Tensor):
        # x: (N, T, L, C) - batch, time, length(cls+patches), channels
        cls_tokens = x[:, :, :1, :]      # 全局token
        patch_tokens = x[:, :, 1:, :]    # 局部patch tokens
        
        # CLS → Patches: 全局信息指导局部
        cls_context = self.cls_to_tokens(
            self.cls_norm(cls_tokens),
            self.token_norm(patch_tokens),
            self.token_norm(patch_tokens)
        )
        
        # Patches → CLS: 局部信息聚合到全局
        tokens_context = self.tokens_to_cls(
            self.token_norm(patch_tokens),
            self.cls_norm(cls_tokens),
            self.cls_norm(cls_tokens)
        )
        
        # 残差连接
        cls_tokens = cls_tokens + self.dropout(cls_context)
        patch_tokens = patch_tokens + self.dropout(tokens_context)
        
        return torch.cat([cls_tokens, patch_tokens], dim=2)
```

**作用**：
- 增强全局-局部特征交互
- 提升模型对面部细节的感知能力
- 改善跨帧一致性建模

## 📊 核心创新点

### 1. **帧间时序建模**
- **Temporal Cross Attention**: 利用相对位置编码建模帧间空间对应关系
- **Bidirectional GRU**: 捕获长期时序依赖和帧间不一致性
- **Multi-scale Pooling**: 不同时间尺度的特征聚合

### 2. **面部组件引导 (FCG)**
- 预定义4个面部组件：lips, skin, eyes, nose
- 从真实人脸提取组件特征作为先验知识
- 通过对比学习强制模型关注关键面部区域

### 3. **跨组件自注意力 (CCSA)**
- CLS token与patch tokens的双向交互
- 增强全局-局部特征融合
- 提升模型对细粒度伪造痕迹的敏感度

### 4. **基于CLIP的迁移学习**
- 冻结CLIP编码器，仅训练轻量级解码器
- 参数高效：仅训练~10%参数
- 利用CLIP的泛化能力应对未见过的伪造类型

## 🔬 关键技术细节

### 1. Temporal Cross Attention实现：
```python
class TemporalCrossAttention(nn.Module):
    def forward(self, q, k):
        # q, k: (N, T, L, H, D)
        # 计算前后帧之间的注意力
        ret = torch.zeros([N, T, L, C], device='cuda')
        
        # 当前帧 → 前一帧
        ret[:, 1:, 1:, :] += self.forward_half(
            q[:, 1:, :, :, :],  # 当前帧query
            k[:, :-1, :, :, :]  # 前一帧key
        )
        
        # 当前帧 → 后一帧
        ret[:, :-1, 1:, :] += self.forward_half(
            q[:, :-1, :, :, :],  # 当前帧query
            k[:, 1:, :, :, :]   # 后一帧key
        )
        
        return ret
```
